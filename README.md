# Dog Vision 🐶

A deep learning app that predicts a dog's breed from a photo (120 breeds).

**Live demo:** https://dog-vision-sayudi.streamlit.app

## How it works
- Transfer learning with MobileNetV2 (TensorFlow / Keras)
- Trained on a 120-breed dog image dataset
- Served as a Streamlit web app

## Files
- `app.py`: the Streamlit app
- `dog_vision_model.h5`: trained model
- `labels.txt`: breed names
- `requirements.txt`: dependencies
